# Customer Segmentation Project

## Project Overview

This project is a Customer Segmentation Dashboard developed using Python, Pandas, Streamlit, Plotly, and K-Means Clustering.

The project analyzes customer demographic and purchasing behavior and divides customers into meaningful groups based on their income, spending score, purchase frequency, and average order value.

## Objective

The main objective of this project is to identify different customer segments and help businesses understand customer behavior.

The project uses K-Means Clustering to group customers into four segments:

- High-Value Customers
- Potential Customers
- Regular Customers
- Budget Customers

## Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- Scikit-learn
- K-Means Clustering
- CSV Dataset
